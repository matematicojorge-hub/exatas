Como publicar o site Exatas Particulares

Por que não dá para usar só o Google Drive? O Drive não abre mais arquivos .html como página — ele mostra o código ou baixa o arquivo. Por isso as aulas precisam ficar num lugar que "sirva" páginas. O GitHub Pages faz isso de graça.

Setor 1 — O que tem na pasta

  • index.html — o site (não precisa mexer).
  • aulas.js — o único arquivo que você edita: link do Meet, links do Drive e a lista de aulas.
  • aulas/matematica, aulas/fisica, aulas/quimica — onde ficam os HTMLs das aulas.

Setor 2 — Publicar pela primeira vez (uns 10 minutos)

  1. Crie uma conta em github.com (gratuita). O nome de usuário vira o endereço, ex.: jorgebasilio.
  2. Clique em New repository. Nome: exatas. Marque Public. Clique em Create repository.
  3. Na página do repositório, clique em uploading an existing file e arraste todo o conteúdo desta pasta (o index.html, o aulas.js e a pasta aulas). Clique em Commit changes.
  4. Vá em Settings → Pages. Em "Branch", escolha main e /(root). Clique em Save.
  5. Em 1 a 2 minutos o site fica no ar em: https://SEU-USUARIO.github.io/exatas/

Setor 3 — Antes de enviar: ajustar o aulas.js

  1. Abra o aulas.js no Bloco de Notas (ou VS Code).
  2. Em meet:, cole o link fixo da sua sala do Google Meet.
  3. Em drive:, cole os links das pastas do Drive (se quiser manter PDFs lá). Deixe "" para esconder o botão.
  4. Confira se o nome em arquivo: é exatamente o nome do seu HTML (maiúsculas, acentos e espaços contam). Dica: evite acentos e espaços nos nomes de arquivo.

Setor 4 — Adicionar uma aula nova (rotina)

  1. No GitHub, entre na pasta da disciplina (ex.: aulas/fisica) → Add file → Upload files → arraste o HTML → Commit changes.
  2. Abra o aulas.js no GitHub → ícone do lápis → copie um bloco { ... },, cole no fim da lista e troque título, disciplina, assunto, descrição e arquivo → Commit changes.
  3. Em 1 minuto a aula aparece no site. Se o arquivo não foi enviado, o card mostra "em breve" sozinho.

Se a aula usar imagens separadas (arquivos .png), envie as imagens para a mesma pasta do HTML.

Setor 5 — E o Google Sites?

Você pode escolher um dos dois caminhos:

  • A) Usar o site novo como principal e mandar aos alunos o endereço do GitHub Pages. No Google Sites, deixe só um botão "Acessar o novo site".
  • B) Manter o endereço do Google Sites: no editor do Sites, Inserir → Incorporar → Por URL, cole https://SEU-USUARIO.github.io/exatas/ e estique o bloco para ocupar a página toda. Os alunos continuam entrando pelo endereço antigo.

Setor 6 — Atenção

  • No GitHub Pages gratuito, qualquer pessoa com o link consegue ver as aulas. Não coloque material que precise ficar restrito a alunos pagantes.
  • Para testar no seu computador antes de enviar, basta abrir o index.html com dois cliques.
